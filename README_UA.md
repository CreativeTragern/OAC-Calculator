# OAC Calculator — мод Fabric для Minecraft 1.21.11

Це **клієнтський** Java-мод за наданим Python-скриптом `OAC Calculator.py`. Він переносить оригінальні розрахунки OAC у графічне меню Minecraft. Python у грі **не потрібен**.

## Виправлено у версії 1.0.1

- Виправлено краш при відкритті меню на Minecraft 1.21.11: `IllegalStateException: Can only blur once per frame` у `OacScreen.render()` — вилучено повторний виклик `renderBackground`.
- Розрахунки, клавіша відкриття та переклади **не змінювались**.
- **Перед встановленням** видали старий `oac-calculator-1.21.11-1.0.0.jar` із `mods`, щоб не тримати обидві версії мода.

## Що додано

- **Меню в стилі калькулятора**: темна панель, введення координат, розділи результатів Main Accel / Fine Accel / Side TNT & Vector Correction / Debug і прокручування коліщатком миші або кнопками ▲/▼.
- **Клавіша відкриття `O` за замовчуванням.** Її можна змінити в **Налаштування → Керування → Призначення клавіш → OAC Calculator → Відкрити калькулятор**.
- **Автоматична мова інтерфейсу:** Українська (`uk_ua`), Російська (`ru_ru`), Англійська (`en_us`). За будь-якої іншої мови Minecraft використовується **англійська**. Окремого перемикача мови немає — інтерфейс бере мову з Minecraft.
- **Normal**: Cannon X/Z та Target X/Z. Початкові координати гармати мають бути **кратними 16**, а ціль — на відстані **щонайменше 100 блоків від центру чанка**. Розрахунок від центра `(cannonX + 8, cannonZ + 8)`.
- **Debug**: прямі `diff X/Z`, більше сирих параметрів, без перевірок розташування чанка і відстані.
- Кнопки **«Поточний чанк»** (використовує початок чанка, де стоїть гравець) та **«Гравець як ціль»**.
- Введені координати зберігаються в пам'яті гри до виходу з Minecraft; перемикання режимів їх не очищує.
- Шар заряду **`nukeLayer = 15`** — як у вихідному Python-файлі.
- Додаткової серверної частини немає, обчислення відбувається локально.

## Як зібрати на Windows

1. Розпакуй ZIP у звичайну папку (бажано без кирилиці у шляху).
2. Встанови **Java JDK 25** у `C:\java\oracleJdk-25` (цей шлях автоматично підхоплює `build.bat`). Також має працювати JDK 21+ через `JAVA_HOME`.
3. Запусти **`build.bat`**. Або в командному рядку папки проєкту виконай `gradlew.bat clean build`.
4. Дочекайся повідомлення `BUILD SUCCESSFUL`. Інтернет потрібен **лише для первинного завантаження** Gradle, Minecraft, Fabric API та інших залежностей.
5. Скопіюй файл **`build\libs\oac-calculator-1.21.11-1.0.1.jar`** у `%APPDATA%\.minecraft\mods` та встанови Fabric API для Minecraft 1.21.11. **Не** встановлюй `-sources.jar`.

У комплекті — справжній Gradle Wrapper (`gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`) із наданого тобою шаблону, а не сторонній завантажувач.

## Важливі примітки

- Це **калькулятор**, а не конструктор гармати й не автоматичне наведення/стрільба. Дані залежать від формул первинного Python-скрипта та конкретної TNT-гармати.
- При дуже великому масштабі GUI на низькій роздільній здатності панель результатів може бути малою. Зменш **Масштаб інтерфейсу (GUI Scale)** у налаштуваннях відео та прокручуй результати.
- Java-логіка формул протестована окремо без Minecraft та зіставлена з 120 наборами координат у Python. Java-код GUI пройшов локальну перевірку синтаксису з тестовими заглушками Minecraft API. **Повна Gradle-збірка і запуск у Minecraft у середовищі підготовки архіву не виконані**: там заблокований доступ до `services.gradle.org` та репозиторіїв залежностей. Тому цей ZIP — **вихідний проєкт**, а не перевірений готовий `.jar`. Якщо збірка на твоєму ПК покаже помилку, надішли її повний лог.
